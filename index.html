How this game works

Requires a free Firebase account (5 min setup, one time only).

Firebase Setup (free, 5 min)

PART A: Create a Firebase Project

1. Open a new tab: console.firebase.google.com

2. Sign in with any Google / Gmail account.

3. Click "Create a project" (or "Add project").

4. Name it anything (e.g. meritus-game). Click Continue.

5. Google Analytics → toggle it OFF.

6. Click "Create project". Wait 15 sec. Click "Continue".

PART B: Create the Realtime Database

7. In the left sidebar, click "Build" to expand it.

8. Click "Realtime Database" (NOT Firestore).

9. Click the "Create Database" button.

10. Location: pick "United States (us-central1)". Click Next.

11. Security rules: select "Start in test mode".

12. Click "Enable". Done — your database is live!

PART C: Get Your Config Code

13. Click the ⚙ gear icon next to "Project Overview" (top-left).

14. Click "Project settings".

15. Scroll down to "Your apps". Click the </> web icon.

16. Name the app anything. Skip Firebase Hosting. Click "Register app".

17. You’ll see a code block. Copy the entire firebaseConfig section:

const firebaseConfig = { apiKey: "AIzaSyB...", authDomain: "meritus-game.firebaseapp.com", databaseURL: "https://meritus-game-default-rtdb.firebaseio.com", projectId: "meritus-game", storageBucket: "meritus-game.appspot.com", messagingSenderId: "123456789", appId: "1:123456:web:abc123" };

18. Copy ALL of it. You’ll paste it on the next screen.
